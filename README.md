# Yuvraj Kunwar

AI engineer. I build document and finance automation, and small tools for working with LLMs and agents.

## What I build

- Invoice and claims automation for aged care: intake, OCR review, approvals, payments and reconciliation.
- Local LLM OCR pipelines that keep documents on the machine that processes them.
- Agent tooling: CLIs and libraries that make LLM workflows safer and easier to check.

## Public repositories

- [prompt-injection-detector](https://github.com/yuvkun10/prompt-injection-detector): layered local detector for prompt injection and jailbreak attempts, as a library, HTTP API and CLI.
- [research-writer-agents](https://github.com/yuvkun10/research-writer-agents): multi-agent pipeline that turns source cards into a cited research brief with a citation audit.
- [api-docs-forge](https://github.com/yuvkun10/api-docs-forge): generates OpenAPI 3.1, Markdown and HTML docs from TypeScript route code.
- [codebase-clarity](https://github.com/yuvkun10/codebase-clarity): CLI that scans a local codebase and writes a plain English architecture report.
- [figma-react-forge](https://github.com/yuvkun10/figma-react-forge): converts Figma JSON into React components, CSS and design tokens.
- [git-standup-bot](https://github.com/yuvkun10/git-standup-bot): CLI that turns local git history into standup summaries.
